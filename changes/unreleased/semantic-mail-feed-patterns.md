Mail, News, and any other app with the same kind of data now open in shared mailbox and feed reader workspaces chosen from what the installed app's interface describes, instead of version-pinned Mail and News screens. Composing, replying, and forwarding appear when the app's own interface describes sending in a way whose result can be checked, and a send whose result is unclear is never repeated without confirmation. Mail's interface does not, so Mail opens for reading and organizing without a composer, and its undo and scheduled sending, saved drafts, attachments, address suggestions, folder management, and account settings are no longer offered. News opens read-only because its interface does not describe article read or star changes in a verifiable form.
