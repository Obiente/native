Deck boards can be shared with people, groups, and teams with edit, share, and manage permissions, archived and restored, and configured for due date notifications and Calendar. Lists can be reordered, cards can be archived, and archived cards can be restored or deleted. Notes adds a favorites filter, favorite changes from the note list, Notes folder and file type settings, and sharing of a note's file when its location can be verified.
