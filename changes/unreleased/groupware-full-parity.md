Calendar, Contacts, and Tasks gain more of the Nextcloud web features inside the app. Events can have reminders and guests, invitations can be answered, and one occurrence of a repeating event can be edited or deleted without changing the rest of the series. Calendars, task lists, and address books can be shared with people and groups, calendars can be published as a read-only link, and deleted calendars, events, and tasks can be restored or removed from the trash bin. The contact birthdays calendar can be turned back on. Contacts hold several labelled emails, phone numbers, addresses, and websites, plus groups, a job title, and a birthday. Address books can be created, renamed, shared, and deleted. Tasks gain subtasks, priority, progress, a start date, tags, and task list management. Every change uses ETag or server preconditions and is confirmed by reading the server again.
